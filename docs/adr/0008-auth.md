# ADR-0008: better-auth, self-hosted

**Status:** Accepted · **Date:** 2026-08-19

## Decision
better-auth for console authentication (OIDC social login, sessions, RBAC roles) —
self-hosted, TS-native. Public-API auth remains our own scoped hashed API keys
(ADR-0003); better-auth never sits on the `/v1` hot path.

## Context
Hosted identity (Clerk/Auth0) would hide exactly the auth engineering this project
exists to showcase; hand-rolling session auth from scratch is undifferentiated risk.

## Consequences
- Auth tables live in our Postgres; sessions inspectable; no vendor dashboard.
- The auth gauntlet story is fully self-owned and demonstrable.
