# ADR-0055: Phase A resumes for the console’s frame plus one room

**Status:** Accepted · **Date:** 2026-09-11 · **Milestone:** M4

## Decision
Phase A resumes at M4 for three artifacts only: a console flow map, `console-shell.html`, and `panel-create.html` drawn inside the approved shell. `annotator-session` and `console-dashboard` stay paused, and the six harvest blockers stay open.

## Context
The console's navigation model was decided inside `console-trace-explorer`, a screen that was deleted and whose successor the BRIEF defers as unstyled, so the decision survived only in the harvest — naming a "classifier switcher" that ADR-0019 retired.

Both extremes were rejected on this project's own evidence. Drawing `panel-create` alone would have let one screen invent the app shell implicitly. Drawing every screen would repeat the failure that paused Phase A: four mockups made six product decisions ahead of PRODUCT.md, including a direct contradiction on consensus-free scoring. A flow map answers cohesion as an information-architecture question for a fraction of what eight wireframes cost, without inventing the contents of screens whose product decisions are unmade.
